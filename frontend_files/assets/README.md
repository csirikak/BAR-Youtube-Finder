# UI assets

The BAR logo and favicon are unchanged copies of the official game assets used
by the original page. They are served locally to avoid an extra CDN connection:

- [Beyond All Reason SVG logo](https://cdn.prod.website-files.com/5c68622246b367adf6f3041d/66f94bf43835f103fe529d9f_BAR-Beyond-All-Reason-Logo-20-Simple-NoGlow-V2.svg)
- [Beyond All Reason favicon](https://cdn.prod.website-files.com/5c68622246b367adf6f3041d/66db72b254c9b267644377f7_favicon%20(2024).png)

BAR branding belongs to its respective owners; this finder is an unofficial
community project.

The original page's Poppins font is served as local Latin WOFF2 subsets in weights
400 and 600, obtained from the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Poppins:wght@400;600&display=swap).
Other scripts use the system font fallback. Poppins is distributed under the
[SIL Open Font License](Poppins-OFL.txt), included here from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/poppins).
